## О проекте

Учебный стенд для отработки параллельных изменений в Git:
независимые ветки, разрешение конфликта по смыслу и отмена
опубликованной ошибки с сохранением истории.

Исходные значения находятся в `config.txt`. Ветки `docs/early` и
`docs/late` создаются от одной исходной ветки `lab-base`.
Каждая меняет одну и ту же строку независимо.

## Требования (из CARDS.md)

- **Карточка EARLY:** служба должна начинать работу в 08:30, окончание пока 17:00
- **Карточка LATE:** служба должна заканчивать работу в 18:00, начало пока 09:00
- **Общее решение:** работа с 08:30 до 18:00, оба запроса действуют одновременно
- **Инцидент:** по ошибке опубликовано `response_minutes=0`, вернуть 60 новым отменяющим коммитом
